# Investigación sobre C#

## ¿Qué es C#?

C# (C Sharp) es un lenguaje de programación desarrollado por Microsoft. Fue creado para facilitar el desarrollo de diferentes tipos de aplicaciones y actualmente forma parte de la plataforma .NET.

C# es un lenguaje orientado a objetos, lo que permite organizar el código mediante clases y objetos. También cuenta con características que facilitan la creación de programas seguros, organizados y fáciles de mantener.

## Características de C#

Algunas de las principales características de C# son:

- Es un lenguaje orientado a objetos.
- Tiene una sintaxis clara y estructurada.
- Permite trabajar con diferentes tipos de datos.
- Incluye estructuras de control como condicionales y ciclos.
- Permite crear aplicaciones para diferentes plataformas.
- Se integra con la plataforma .NET.
- Es utilizado para el desarrollo de videojuegos mediante Unity.
