# **Investigación sobre React**

## **1. ¿Qué es React?**

**React** es una biblioteca de **JavaScript** utilizada para crear interfaces de usuario para páginas y aplicaciones web. Fue desarrollada originalmente por **Facebook**, actualmente conocida como **Meta**.

React permite construir una página web utilizando diferentes partes llamadas **componentes**. Cada componente puede representar una parte específica de la página, como un menú, un botón, una lista de productos o un formulario.

Por ejemplo, una página web puede dividirse en:

- **Encabezado**
- **Menú de navegación**
- **Contenido principal**
- **Botones**
- **Formularios**
- **Pie de página**

Esto permite que el código sea más organizado y fácil de reutilizar.

---

## **2. ¿Cuál es la función de React?**

La función principal de **React** es facilitar la creación de **interfaces de usuario dinámicas e interactivas**.

React permite que una página responda a las acciones que realiza el usuario. Por ejemplo, cuando una persona presiona un botón, escribe información en un formulario o agrega un producto a un carrito, React puede actualizar la información necesaria sin tener que recargar toda la página.

Entre sus principales funciones se encuentran:

- **Crear interfaces de usuario interactivas.**
- **Organizar una página mediante componentes.**
- **Reutilizar partes del código.**
- **Actualizar la información de la página de manera eficiente.**
- **Manejar eventos como clics y formularios.**
- **Controlar información que cambia durante el uso de una aplicación.**
