## Introduccion
El pseudocódigoes una forma de escribir los pasos de un programa usando palabras comunes y reglas sencillas. Sirve para que las personas entiendan la lógica de un algoritmo antes de pasarlo a un lenguaje de programación real. No se puede ejecutar en una computadora.

## ¿que es el pseudocodigo ?
el pseudocodigo es una forma de representar un algorit    utilizando  palabras y estructura similares  a las de un lenguaje de programacion  pero sin seguir  estrictamente las reglas de un  lenguaje especifico  su objetivo prnciopal es facilitar la comprension de la logica que debe seguir un programa antes de  implementarlo

## aracteristicas del pseudocodigo
- es facil de leer y comprender
- permite reprsentar la logica de un algoritmo 
- no   depende de n lenguaje de programacion especif
- facilita   la planifica     de un programa 
- permite detectar errores de logica  antes de program
- puede utiliizar estructuras condiciones y ciclos

## ¿para que sirve?

El pseudocódigo sirvepara planificar, diseñar y entender la lógica de un programa antes de escribir código real. Mezcla nuestro idioma con la estructura de la programación, permitiendo resolver problemas paso a paso sin preocuparte por las reglas difíciles de una computadora.

## ventajas y desventajas
 Ventajas | Desventajas |
|---|---|

| Ayuda a organizar las ideas. | No puede ejecutarse directamente. |
| Facilita la detección de errores lógicos. | Puede variar según la herramienta utilizada. |
| Permite planificar antes de programar. | Necesita convertirse posteriormente en código. |

## estructura basica del pseudocodigo
1. inicio y final del algoritmo
2. declaracion de variables
3. entrada  de datos
4. procesamiento de informacion
5.salida de resultados
6. estructura  condicionales
7. estructura repetitivas

# 9. Pseudocódigo vs lenguaje de programación
| Pseudocódigo | Lenguaje de programación |
|---|---|
| Se utiliza para representar la lógica. | Se utiliza para crear programas ejecutables. |
| Tiene una sintaxis flexible. | Tiene reglas sintácticas específicas. |
| No depende de un lenguaje concreto. | Depende del lenguaje utilizado. |
| Es fácil de modificar durante la planificación. | Debe cumplir las reglas del lenguaje. |

## 9. PSeInt
pseint es  una herramienta para aprender sobre logica y algoritmos de programacion  y 
los fundamentos de la programación mediante pseudocódigo.

Permite escribir algoritmos utilizando instrucciones como
Escribir, Leer, Si, Mientras y Para que luego son muy parecidas  a funciones de otros lenguajes como if , else, print,               while

Estas instrucciones permiten practicar conceptos fundamentales
de programación antes de pasar a lenguajes de programacin mas complejos como  javasript, java, c3, c++
