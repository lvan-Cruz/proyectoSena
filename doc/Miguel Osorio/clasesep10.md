# Dart

Dart es un lenguaje de programación desarrollado y respaldado por Google. Es un lenguaje moderno, fuertemente tipado y orientado principalmente al desarrollo de aplicaciones multiplataforma. Actualmente es especialmente conocido por ser el lenguaje que utiliza Flutter para crear aplicaciones.

Características principales
Tiene tipado estático, lo que ayuda a detectar errores relacionados con los tipos de datos.
Incluye null safety, que ayuda a prevenir errores causados por valores nulos.
Permite programación orientada a objetos.
Puede compilarse para diferentes plataformas, incluyendo dispositivos móviles, computadores y web.
Cuenta con Hot Reload, una función muy útil en Flutter que permite ver rápidamente los cambios realizados en una aplicación.

## ¿Para qué se utiliza?

Dart se utiliza principalmente para desarrollar:

* Aplicaciones móviles.
* Aplicaciones de escritorio.
* Aplicaciones web.
* Aplicaciones y servicios de backend.

*Ejemplo:* una aplicación creada con Flutter puede utilizar Dart para funcionar tanto en Android como en iOS y otras plataformas.

# Visual Basic

Visual Basic (VB) es un lenguaje de programación desarrollado por Microsoft. Es un lenguaje orientado a objetos que forma parte del ecosistema .NET y permite desarrollar aplicaciones de manera relativamente sencilla.

## Características principales

Es orientado a objetos.
Tiene una sintaxis diseñada para ser relativamente fácil de leer.
Se integra con tecnologías de Microsoft y .NET.
Permite crear aplicaciones con interfaces gráficas.
Puede utilizarse para desarrollar aplicaciones de escritorio y otros tipos de aplicaciones .NET.

## ¿Para qué se utiliza?

Visual Basic puede utilizarse para desarrollar:

Aplicaciones de escritorio.
Aplicaciones para Windows.
Programas empresariales.
Aplicaciones basadas en .NET.
Interfaces gráficas mediante tecnologías como Windows Forms.

Ejemplo: se puede utilizar para crear un programa de escritorio con botones, formularios, cuadros de texto y otros elementos visuales.

# JavaScript

JavaScript (JS) es un lenguaje de programación multiplataforma y dinámico, especialmente conocido por utilizarse para agregar interactividad a las páginas web. También puede utilizarse fuera del navegador mediante entornos como Node.js.

## Características principales

Es un lenguaje dinámico.
Soporta diferentes paradigmas, como programación orientada a objetos, imperativa y funcional.
Puede ejecutarse directamente en los navegadores.
Permite modificar elementos de una página mediante el DOM.
Puede utilizarse tanto en el frontend como en el backend.
Utiliza programación asíncrona, muy importante para aplicaciones web.
¿Para qué se utiliza?

## JavaScript se utiliza para:

Crear páginas web interactivas.
Crear aplicaciones web.
Crear animaciones y efectos.
Desarrollar aplicaciones del lado del servidor.
Crear aplicaciones de escritorio y otros tipos de software mediante diferentes entornos.

*Ejemplo:* cuando una página web tiene un botón que abre un menú, valida un formulario o cambia contenido sin recargar toda la página, JavaScript puede estar encargado de esa interacción.
