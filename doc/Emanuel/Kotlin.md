KOTLIN
## Introducción
Kotlin es un lenguaje de programación moderno, creado por JetBrains. Es un lenguaje multiplataforma, sencillo y seguro, que se utiliza principalmente para desarrollar aplicaciones, especialmente aplicaciones para Android. También permite crear programas para servidores, páginas web y otros sistemas.

## ¿Qué es Kotlin?
Kotlin es un lenguaje de programación de código abierto que combina características de la programación orientada a objetos y la programación funcional.
Una de sus principales características es que tiene una sintaxis sencilla y permite escribir código más corto y fácil de mantener.
