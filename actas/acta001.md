## 2. Desarrollo de la reunión

Se dio inicio a la reunión en el Ambiente ADSO 1 a las 8:00 a. m., con la participación de todos los integrantes del grupo.

Durante la reunión se analizaron diferentes opciones para desarrollar el proyecto final del SENA. Después de discutir las propuestas, se decidió realizar el proyecto para la Farmacia Puerto Millo, ubicada en la Carrera 19 # 47-02, barrio Normandía, Soledad, Atlántico.

El propietario o encargado de la droguería es Arnold de la Hoz. Se identificó que la droguería cuenta actualmente con dos sucursales y necesita implementar herramientas tecnológicas para mejorar la gestión de sus productos y facilitar la atención a sus clientes.

## 3. Necesidades identificadas

- Crear una página web para mostrar los productos disponibles.
- Desarrollar una aplicación que permita a los clientes realizar pedidos.
- Crear una base de datos tipo inventario para controlar los productos.
- Mejorar la administración de los productos de las dos sucursales.
- Facilitar el proceso de compra y solicitud de productos por parte de los clientes.


## 4. Acuerdos

Se acordó que el grupo desarrollará como proyecto final SENA un sistema tecnológico para la Farmacia Puerto Millo, ubicada en la Carrera 19 # 47-02, barrio Normandía, Soledad, Atlántico.

El proyecto estará compuesto principalmente por:

- Una página web.
- Una aplicación para realizar pedidos.
- Una base de datos para la gestión del inventario.
